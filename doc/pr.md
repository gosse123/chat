# Probéme 
Aujourd'huit on peut pas communiquer dans le terminal en local entre plusieurs terminaux, sa faire que on se rabat sur des solution comme whatsapt qui consomme notre connection .

# Utilisateurs
- les developeurs/administrateurs systémes, qui bossent  dans le terminal toute la journée

- les etudiants/apprenant en resau qui veulent un outils pour tester la communication entre  plusieurs pc.

# Cas d'utilisation
- Tester la communication dans un résau.
- echanger des message entre plusieurs machine meme reseau.

# Limites d'actions
- permet pas de creation de compte utilisateur .
- permet pas le communication hos réseau.

# Ce qu'on résout 
Notre solution permte la communication entre plusieurs pc qui appatienent au meme reseau.
